# כלכלת הבית

אתר לניהול הכלכלה של המשפחה, בעברית ומותאם לטלפון. האתר מראה את התזרים, את הנכסים והחובות, תחזית עד 5 שנים קדימה ויעדי צמיחה.
הנתונים נשמרים במסד נתונים אמיתי (Supabase), עם כניסה בסיסמה. אפשר להחליף טלפון, הנתונים לא נעלמים.
**העלות: ₪0.** Supabase ו-GitHub Pages חינמיים בהיקף של משפחה.

---

## מה יש בשלב 1

| מסך | מה רואים |
|---|---|
| **ראשי** | מחולק לשלושה חלקים נפרדים: **תזרים החודש** (הכנסות, הוצאות, יתרה חודשית, התחייבויות קבועות, צפי בבנק לסוף החודש), **נכסים וחובות** (כסף בחשבונות, מינוס, הלוואות, נכסים, שווי נקי), **תמונה משפחתית** (מדדי בריאות בצבעים, לאן הולך הכסף באחוזים, מקורות הכנסה, קבוע מול משתנה, חלוקה לפי בני הזוג, 6 חודשים אחרונים), ויעדים |
| **תזרים** | לכל חודש: הכנסות והוצאות בפועל מול צפי, חיובים והכנסות שעוד צפויים, עם כפתור "התקבל / שולם", יתרה יומית צפויה, פילוח לפי קטגוריות, ותנועות |
| **הון וחובות** | חשבונות בנק (שלי, של אשתי, משותף) עם יתרה ומסגרת, כרטיסי אשראי עם יום חיוב וחיוב צפוי, הלוואות (יתרה, החזר, ריבית, תשלומים שנותרו, תאריך סיום), נכסים, וגרף התפתחות של המינוס והחובות |
| **תחזית** | **החודש**: יתרה יומית לפי תאריכים אמיתיים, ומה יורד מתי. **12 חודשים**: הכנסות, הוצאות ועודף בכל חודש. **5 שנים**: שווי נקי, חובות ויתרת בנק, טבלה שנתית, ו"מתי מתפנה כסף" כשהלוואות נגמרות |
| **עוד** | יעדי צמיחה, הכנסות והוצאות קבועות, כל התנועות (חיפוש ועריכה), ייבוא מ-Excel/CSV, ייצוא וגיבוי ל-Excel, הגדרות, הזמנת משתמש נוסף |
| **+** | הוספה מהירה של הוצאה או הכנסה: סכום, קטגוריה, שמירה |

**עקרונות:**
- הכנסה צפויה לא נספרת כאילו התקבלה, עד שלוחצים "התקבל".
- הוצאות בכרטיס אשראי נספרות בהוצאות החודש, אבל יורדות מהבנק רק ביום החיוב, ולא נספרות פעמיים.
- הזנה פעם אחת: הכנסות והוצאות קבועות מוגדרות פעם אחת, ומופיעות אוטומטית בכל חודש ובתחזית.
- בייבוא אפשר להעלות את אותו קובץ שוב בלי כפילויות.
- אין חיבור ישיר לבנק. מזינים ידנית או מייבאים קובץ שמורידים מאתר הבנק או חברת האשראי.

## התקנה (בערך 15 דקות, פעם אחת)

### שלב א: מסד הנתונים (Supabase)
1. נרשמים ב-[supabase.com](https://supabase.com) ויוצרים **New project**. בוחרים אזור קרוב (למשל Frankfurt) ושומרים את הסיסמה.
2. בתפריט: **SQL Editor** ← **New query**. מדביקים את כל התוכן של הקובץ `supabase/schema.sql` ולוחצים **Run**. אמורה להופיע ההודעה Success.
3. **Authentication** ← **Sign In / Providers** ← לוודא ש-**Email** מופעל.
   מומלץ לכבות את **Confirm email**, כדי שלא יצטרכו לאשר מייל בהרשמה.
4. **Project Settings** ← **API** (או **Data API**): מעתיקים את **Project URL** ואת המפתח **anon / publishable**.
5. פותחים את הקובץ `js/config.js` ומדביקים את שני הערכים במקום `YOUR_PROJECT` ו-`YOUR_ANON_KEY`.

> המפתח הזה ציבורי מטבעו, ומותר שיופיע באתר. ההגנה על הנתונים היא כללי ההרשאות (RLS) שבסכמה: כל משתמש רואה רק את משק הבית שלו.
> **אסור** להכניס לאתר את המפתח `service_role`.

### שלב ב: האתר (GitHub Pages)
1. ב-[github.com](https://github.com) יוצרים **New repository** (אפשר פרטי או ציבורי).
2. **Add file** ← **Upload files**, ומעלים את כל הקבצים והתיקיות כמו שהם: `index.html`, `css/`, `js/`, `supabase/`.
3. **Settings** ← **Pages** ← Source: **Deploy from a branch** ← Branch: `main`, תיקייה `/ (root)` ← **Save**.
4. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-משתמש>.github.io/<שם-ה-repository>/`.
5. חוזרים ל-Supabase: **Authentication** ← **URL Configuration** ← **Site URL** = הכתובת של האתר.

### שלב ג: כניסה ראשונה
- נכנסים לאתר ← **הרשמה** עם מייל וסיסמה. משק בית חדש נוצר אוטומטית.
- **הוספת בת הזוג:** עוד ← הגדרות ← הזמנה עם המייל שלה. אחר כך היא נרשמת לאתר עם אותו מייל, ורואה את אותם נתונים.
- בטלפון: פותחים את האתר ← בתפריט הדפדפן בוחרים **הוספה למסך הבית**, וזה נפתח כמו אפליקציה.

### לנסות לפני ההתקנה
פותחים את `index.html` בלי למלא את `config.js` (או מוסיפים `#demo` לכתובת), ובוחרים **מצב הדגמה עם נתוני דוגמה**. בהדגמה הנתונים נשמרים רק בדפדפן.

## סדר מומלץ להזנה ראשונה
1. **הון וחובות** ← חשבונות בנק עם היתרה של היום ומסגרת האשראי.
2. **הון וחובות** ← כרטיסי אשראי: יום חיוב, חיוב צפוי, ומאיזה חשבון יורד החיוב.
3. **הון וחובות** ← הלוואות, משכנתאות וחובות, עם מספר תשלומים שנותרו וריבית אם ידועה.
4. **עוד ← קבועים** ← משכורות, שכירות, הוראות קבע (ארנונה, גן, ביטוחים…).
5. **הון וחובות** ← נכסים: הדירה בלוד (50%), חסכונות, קרן השתלמות.
6. **עוד ← יעדי צמיחה**, למשל "לצאת מהמינוס עד יוני" או "שווי נקי של 500 אלף בעוד 3 שנים".

**שגרה:** הוצאות שוטפות דרך **+**. פעם בשבוע לאשר ב"תזרים" מה התקבל ומה שולם. פעם בחודש לעדכן יתרות בנק ולייבא פירוט אשראי.

## מבנה הקבצים
```
index.html            מעטפת האתר
css/app.css           עיצוב (כולל מצב כהה)
js/config.js          חיבור ל-Supabase  ← ממלאים פעם אחת
js/calc.js            כל החישובים: יתרות, תזרים, תחזיות, יעדים, מדדים, ייבוא
js/data.js            שמירה וטעינה (Supabase, או מצב הדגמה בדפדפן)
js/app.js             המסכים והטפסים
supabase/schema.sql   טבלאות והרשאות ← מריצים פעם אחת ב-Supabase
```
ספריות חיצוניות (נטענות מ-CDN, בלי התקנה): supabase-js, Chart.js, SheetJS (ל-Excel).

## הערות
- בתוכנית החינמית Supabase עשויה להשהות פרויקט שלא היה בו שימוש תקופה. במקרה כזה מפעילים אותו מחדש בלחיצה בלוח הבקרה, והנתונים נשמרים.
- גיבוי: עוד ← ייצוא ל-Excel, פעם בחודש.
- התחזית היא הערכה: היא מבוססת על הקבועים, על ההלוואות ועל ממוצע ההוצאות המשתנות ב-3 החודשים האחרונים. ככל שיש יותר היסטוריה, היא מדויקת יותר.
